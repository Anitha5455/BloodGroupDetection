# 🩸 Blood Group Detection using CNN

This project detects human blood groups using **Convolutional Neural Networks (CNN)**.  
It was developed and trained in **Google Colab** using **TensorFlow, OpenCV, NumPy, and Pandas**.

---

## 📘 Project Description

This deep learning project aims to classify **blood group types** from image data.  
It loads blood sample images from Google Drive, preprocesses them, builds a CNN model, trains it, and saves the trained model for future predictions.

The CNN model automatically learns features from blood sample images and predicts their blood group (like A, B, AB, O).
